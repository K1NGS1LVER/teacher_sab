# Build compatibility alias

`build` is a deprecated compatibility alias. This skill name remains available
for existing installations and prompts, but new prompts and documentation
should use `build-along`.

Load and follow `../build-along/SKILL.md` and
`../build-along/references/ladder.md`. If this harness cannot follow that
relative reference, apply the learner-authored build-ban and stage-loop rules
from the `teach` skill's `references/build-mode.md`.
